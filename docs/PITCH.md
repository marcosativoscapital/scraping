## O problema

Precisamos de **250 leads qualificados em 5 semanas** em 4 verticais.

Soluções de mercado:
- ⚠️ Custo: **R$ 1.500–10.000/mês**

## A solução

**Scraper próprio + Gemini + Extensão Chrome.**

✅ Coleta de fontes públicas brasileiras (SPA/MF, Bacen, oHub, ABStartups)
✅ IA classifica, pontua e personaliza
✅ CSV pronto para Apollo / Smartlead / Heyreach
✅ Extensão Chrome captura LinkedIn sem risco

## Como funciona

```
1. SCRAPE      → fontes públicas oficiais
2. CLAUDE      → extrai, classifica, pontua
3. ENRICH      → CNPJ + decisor + e-mail
4. PERSONALIZE → frase única por empresa
5. EXPORT      → CSV padronizado
```

Cada lead vem com **score 0–100** e **frase de outbound pronta.**

🌐 Captura visual no LinkedIn Sales Navigator

## Stack técnico

- **Python** + Playwright (scraping)
- **Gemini API** (parsing, scoring, personalização)
- **FastAPI** (servidor local)
- **Manifest V3** Chrome (extensão)
- **BrasilAPI + Hunter.io** (enrichment)

100% local. Sem cloud. Sem dependência de fornecedor.
